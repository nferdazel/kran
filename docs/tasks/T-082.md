# T-082 — `ledger` laporan saldo GL (opening/period/closing)

Status: **IN_PROGRESS**. Spec §9.1, keputusan **D-096** (menutup O-083). Deps: T-074, T-080.

## Scope

1. Domain `report.nim`: `BalanceSource` (`ledger`|`snapshot`), `BalanceLine`
   (opening/period debit-kredit terpisah + helper `closing*`), `GlBalances`; `SnapshotTotal`
   + `snapshotMatches` untuk gerbang rekonsiliasi.
2. Repo `report_repo.nim`: `balancesFromLedger(startsOn, endsOn)` — **satu** query agregasi
   (opening sebelum `startsOn`, mutasi dalam rentang inklusif), `snapshotTotals(asOf)`.
3. Handler `GET /api/v1/ledger/balances?periodId=` (izin `ledger.journal.read`, dua gerbang
   institusi): `source` + `computedAt` (ISO-8601 UTC), baris = akun bergerak **atau** saldo awal ≠ 0.
4. Kontrak OpenAPI (`LedgerBalances`) + regenerasi klien TS.
5. Test integrasi `itapi_ledger.nim`: batas tanggal inklusif, akun tanpa mutasi ber-saldo-awal,
   akun tanpa apa pun absen, `opening + mutasi = closing`, periode CLOSED pakai snapshot,
   403 tanpa izin, 404 periode tidak ada.

## Asumsi / keputusan desain

- **Sumber angka tetap jurnal.** `journal_line` adalah kebenaran; satu query agregasi menghasilkan
  opening (sebelum `startsOn`) + mutasi (inklusif) + closing (turunan), sesuai D-096.
- **`source=snapshot` hanya bila periode CLOSED dan terekonsiliasi (D-096).** Gerbang rekonsiliasi
  = cache `balance_snapshot` di `endsOn` sudah dibangun **dan** angkanya sama dengan hasil jurnal
  (per akun). Bila belum ada/tidak cocok → `source=ledger` (default "hitung dari jurnal"). Snapshot
  **tidak pernah** dipakai untuk periode OPEN.
- Saldo awal periode = akumulasi jurnal **sebelum** `startsOn`; batas inklusif (`BETWEEN`).
- Nilai uang lewat `Money`; respons desimal 4 (`toDecimalString`).
