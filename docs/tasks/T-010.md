# T-010 — Shell aplikasi web + design token + tema + i18n + baseline a11y

Spec: §14 (frontend SvelteKit + TS, struktur `apps/web`, indikator business date), §15 (design
token, tema light/dark, kontras, status bukan hanya warna, motion), §16 (i18n id+en, Paraglide,
format angka/uang, pemeriksaan katalog), §17 (a11y WCAG 2.2 AA, keyboard-only, axe), §18.2 (versi
dependency dipin), §7 (workspace TS `apps/*` + `packages/*`).

## Scope

1. `pnpm-workspace.yaml` + root `package.json` (skrip paket TS; satu pintu perintah tetap `./task`).
2. `packages/config` — `tsconfig.base.json` bersama.
3. `packages/i18n` — katalog `messages/{id,en}.json` + proyek inlang untuk Paraglide.
4. `packages/ui` — `tokens/tokens.css` (token semantik light/dark), `src/components.css`
   (komponen dasar pada elemen semantik), `src/contrast.ts`, test kontras `tokens.contrast.test.ts`.
5. `apps/web` — SvelteKit 3 SPA (`adapter-static` + fallback): shell (`+layout.svelte`),
   beranda (`+page.svelte`), `lib/app/{theme,i18n,format}.ts`.
6. `tools/i18ncheck` + test — gate katalog i18n (spec §16.3), dipakai `./task i18n`.
7. Playwright: `apps/web/tests/e2e/{a11y,keyboard}.spec.ts` + `playwright.config.ts`.
8. `./task e2e` diisi (kontras token + svelte-check + Playwright) dan job CI `web-e2e`.

## Keputusan desain

- **SvelteKit 3 mengubah dua hal besar** (ditemukan saat build, bukan ditebak):
  `svelte.config.js` tidak dipakai lagi (konfigurasi lewat plugin `sveltekit()` di Vite), dan
  alias `$lib` dihapus (dipakai `#lib` + peta `imports` di `package.json`). `tsconfig.json`
  sekarang `extends: "$app/tsconfig"`.
- **SPA murni**: `src/routes/+layout.ts` mematikan SSR; tema ditetapkan skrip inline di `app.html`
  sebelum render (cegah flash, §15.3).
- **Kontrol tema & bahasa = grup radio native**, bukan `<select>`/tombol kustom. Alasannya
  konkret: pada Chromium headless yang dipakai verifikasi, `<select>` tidak dapat diubah lewat
  keyboard sama sekali (terbukti: ArrowDown/Enter tidak mengubah nilai), sedangkan radio native
  urutan fokus + panah + `change`-nya dapat diuji sebagai keyboard-only (§17.2). Efek sampingnya
  positif: semantik lebih kaya (fieldset/legend), satu tab stop per grup.
- **Tema = atribut `data-theme` di `<html>`**, bukan kelas per komponen: token yang berganti,
  komponen tidak tahu-menahu soal tema (§15.3).
- **Katalog i18n = satu berkas datar per locale** (`messages/id.json`, `messages/en.json`) dengan
  prefiks namespace pada nama key (`common_*`), bukan `messages/<locale>/<namespace>.json`.
  Alasan empiris: plugin `@inlang/plugin-message-format` **tidak menghasilkan satu pun pesan**
  dengan pola `{locale}/{namespace}.json` (compile sukses tapi katalog kosong); pola
  `{locale}.json` bekerja. Namespace tetap terjaga sebagai prefiks key dan **dipaksakan**
  `tools/i18ncheck` (key wajib `namespace_segmen`). Terverifikasi: `i18ncheck` menolak key `title`.
- **Perubahan bahasa me-render ulang subtree** (`{#key locale}` di layout). Fungsi pesan Paraglide
  bukan store Svelte; alternatifnya menyalin tiap pesan ke store — lebih kompleks tanpa manfaat
  untuk shell tanpa state yang perlu dipertahankan.
- **Jamak dipilih di kode** (`formatAccountCount` + `Intl.PluralRules` + satu pesan per bentuk),
  karena Paraglide v2 tidak menafsirkan sintaks ICU mentah `{n, plural, …}`: string-nya rusak jadi
  placeholder saat kompilasi (terbukti: pesan hasil compile berbunyi
  `"${i?.["n, plural, =0 {Belum ada rekening"]} other }"`).
- **Plugin Paraglide diambil dari CDN jsdelivr versi pin** (`@inlang/plugin-message-format@4.5.2`,
  `@inlang/plugin-m-function-matcher@2.3.2`). Ini satu-satunya jalan yang bekerja di mesin ini:
  registry npm privat (`artifactory.pegadaian.co.id`) tidak resolve sehingga paket plugin tidak
  bisa dipasang dari sana. Cache unduhan tidak di-commit. Dicatat O-021.
- **`./task e2e` memanggil binary lokal `node_modules/.bin/*`, bukan `pnpm run`**: pnpm 10+
  memasang ulang dependency lebih dulu bila dianggap tidak sinkron, dan install itu butuh registry
  → bisa menggantung di mesin ini. Binary lokal deterministik dan tetap benar di CI setelah
  `pnpm install` (job `web-e2e`).
- **Versi dependency dipin** (tanpa `^`) di `apps/web/package.json` + `packages/ui/package.json`
  (§18.2), mis. `svelte@5.57.2`, `@sveltejs/kit@3.0.1`, `vite@8.3.4`, `@playwright/test@1.64.0`.

## Batasan yang diketahui (jujur)

1. **Belum ada visual regression test** (§15.8). Screenshot baseline bergantung OS/font; baseline
   yang dibuat di macOS akan gagal di runner Linux. Ditunda sampai ada CI yang menghasilkan
   baseline — dicatat O-022.
2. **Belum ada komponen headless** (bits-ui/Melt UI) dan komponen kompleks (dialog, combobox,
   tabel ter-virtualisasi); `packages/ui` baru memuat token + kelas dasar pada elemen semantik.
   Menyusul bersama layar bisnis pertama (T-012+).
3. **Belum ada ESLint** (`eslint-plugin-svelte` + aturan a11y sebagai error, §17.2). Gate a11y
   Fase 0 = axe (Playwright) + `svelte-check`; aturan lint belum ada → O-023.
4. **Lockfile JS belum ada.** `pnpm install --lockfile-only` gagal di mesin ini
   (`ERR_PNPM_NO_OFFLINE_META` untuk `@bytecodealliance/jco-transpile`, registry privat tidak
   resolve). Job CI memakai `pnpm install` biasa sampai lockfile bisa dibuat → O-020.
5. **Indikator business date masih placeholder** ("belum tersambung"); nilainya butuh API
   business date (T-012).
6. **Format uang di frontend menerima string desimal** (spec §13) dan memakai `Number` hanya untuk
   tampilan; belum ada jalur data nyata sehingga belum diuji terhadap nilai besar (presisi).
7. **Ranking halaman**: hanya beranda. Judul halaman unik sudah disiapkan di `+page.svelte`.
8. **Belum ada TanStack Query/Superforms/bits-ui** (§14.1) — baru masuk saat ada data nyata,
   supaya tidak ada abstraksi tanpa pemakai.
