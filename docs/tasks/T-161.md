# T-161 — Modul `lending`: skeleton + model pinjaman

**Status**: DONE (1 Nov 2026) · **Keputusan**: D-180 · **Deps**: T-142 (pola modul), D-002

## Scope

Model dan skema **saja**. Tidak ada endpoint, tidak ada UI, tidak ada task day-close (itu T-163…T-167).

1. `modules/lending/` dengan susunan yang sama seperti `deposit`: `domain/`, `infrastructure/`,
   `migrations/`, `seeds/`, `tests/`, `api.nim`, `README.md`, `MODULE.md`.
2. Migrasi expand-only:
   - `lending.loan_product` + `lending.loan_product_version` (versi + `DRAFT`/`ACTIVE` + maker/checker,
     pola `product`/T-086) — atribut: metode jadwal (`FLAT`/`EFFECTIVE`/`ANNUITY`), tenor
     (`min`/`max`/default), suku bunga/margin (per tahun, basis hari), dan urutan alokasi pembayaran
     (daftar terurut — D-180 butir 4).
   - `lending.loan` (akad/fasilitas): `party_id`, `product_version_id`, `branch_id`, `principal`,
     `disbursed_on`, `maturity_on`, `status` (`APPLIED`/`APPROVED`/`ACTIVE`/`CLOSED`/`WRITTEN_OFF`),
     pembuat + penyetuju (bukan orang yang sama).
   - `lending.installment`: satu baris per jatuh tempo (`no`, `due_on`, `principal_due`,
     `interest_due`, `total_due`, `paid_principal`, `paid_interest`, `paid_penalty`,
     `paid_on`) — D-180 butir 1: jadwal disimpan per baris, bukan dihitung ulang saat dibaca.
   - `lending.loan_balance` (cache saldo pokok/bunga tunggakan) dengan CHECK `>= 0`, pola
     `deposit.account_balance`.
   - Grant runtime + trigger imutabilitas baris jadwal yang sudah dibayar (pola `deposit/0005`).
3. Seed parameter (`lending/seeds/params.yaml`) hanya yang dibutuhkan model: metode default produk,
   urutan alokasi, ambang DPD & persentase PPAP **bertanda `NEEDS-COMPLIANCE-REVIEW`** (D-180
   butir 2–3). Nilai uji di suite tidak memakai seed produksi.
4. `domain/` tipe: `LoanProduct`, `Loan`, `Installment`, `ScheduleMethod`; tidak ada `float`, uang
   lewat `Money`.
5. `api.nim` kosong-terkontrol (seperti `deposit/api.nim`) — modul hanya bicara lewat situ nanti.

## Non-goals

- Kalkulasi jadwal (T-162), pengajuan/pencairan (T-163/T-164), task day-close (T-166/T-167).
- Syariah (Fase 8). Jangan menyiapkan kolom akad yang belum dipakai.
