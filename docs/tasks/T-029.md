# T-029 — Pump realtime pulih setelah koneksi putus (O-029)

Status: READY
Prioritas: P1 (batch "Fase 0 tahan banting")

## Kenapa
`pumpLoop` menangkap `CatchableError` lalu berhenti selamanya: setelah blip DB/jaringan, realtime mati diam-diam dan `sweepSessions()` ikut berhenti (sesi tercabut tetap hidup sampai kedaluwarsa).

## Rencana
- Bungkus siklus hidup pump: acquire → LISTEN → loop; bila koneksi gagal, tutup, tunggu backoff (batas atas), lalu sambung ulang — tanpa kehilangan peristiwa (baca tabel dari `lastEventId`, bukan hanya NOTIFY).
- Log saat putus dan saat pulih; `ready` mengikuti keadaan sebenarnya.
- Test: injeksi `pg_terminate_backend` pada backend pump → peristiwa baru tetap terkirim setelah pulih; dan `sweepSessions` jalan lagi.

## Catatan
Menyentuh realtime; jangan sampai pump ganda (dua thread) saat pulih.
