# T-081 — O-090: seed parameter ikut jalur migrasi/deploy

**Status:** IN PROGRESS (kode selesai; menunggu bukti deploy)
**Sumber:** O-090 (temuan go-live Fase 1, 20 Okt 2026).

## Scope

Deploy me-restart worker **sebelum** parameter tersemai. Worker menolak start (exit 2) bila
`ledger.posting.*` belum punya nilai aktif, dan pipeline tidak pernah menjalankan seed — jadi deploy
pertama setiap rilis yang menambah parameter meninggalkan worker mati sampai seed manual.

Perbaikan: subperintah `--role=migrate --seed` (memakai `dbtools/lib` yang sudah diimpor aplikasi)
dan langkah seed di `deploy-vps.sh` **setelah** biner ditukar, **sebelum** unit di-restart.
