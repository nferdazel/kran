# T-002 — `shared/kernel` (shared kernel kecil & stabil)

- **Status**: IN_PROGRESS
- **Spec**: §5.2 (shared kernel kecil & stabil, tanpa "utils" serbaguna), §9.1(2) uang
  `Money` fixed-point, §9.1(6) tiga jenis tanggal, §9.1(8) UUIDv7, §12.1 (tipe uang sendiri),
  §12.2 (error `Result[T, AppError]`, satu berkas ≈ ≤300 baris), §13 (audit context,
  `problem+json` `code`/`i18nKey`/`params`), §27.A (`MODUL-NNNN`), ADR-011.
- **Deps**: T-001.

## Scope

Membuat shared kernel di bawah `shared/kernel/`, plus umbrella `shared/kernel.nim` supaya
`import kernel` bekerja. Modul: `result`, `money`, `rate`, `businessdate`, `clock`, `ids`,
`auditcontext`.

Berkas yang disentuh (semua baru):

- `shared/kernel.nim` (umbrella; re-export semua modul kernel)
- `shared/kernel/result.nim` — `Result[T, E]`, `AppResult[T]`, `AppError`
- `shared/kernel/money.nim` — fixed-point skala 10⁴, int64 minor units (tanpa float)
- `shared/kernel/rate.nim` — fixed-point skala 10⁶ (tanpa float)
- `shared/kernel/businessdate.nim` — kalender sendiri (tanpa `std/times`)
- `shared/kernel/clock.nim` — `Clock`/`SystemClock`/`FakeClock`
- `shared/kernel/ids.nim` — UUIDv7 + correlation id
- `shared/kernel/auditcontext.nim` — konteks audit (§13)
- `shared/kernel/tests/` — `tresult`, `tmoney`, `trate`, `tbusinessdate`, `tclock`, `tids`,
  `tauditcontext`, `tprop_money`, `tprop_rate` + `support/propgen.nim` (harness property test)
- `docs/tasks/T-002.md` (berkas ini)

**Tidak disentuh**: `shared/kernel/paramkey.nim` (sudah ada, kontrak beku), `tools/`,
`modules/`, `apps/`, skrip `./task`.

## Kontrak API

Dibekukan sesuai instruksi task (dipakai modul lain). Identifier Inggris, doc/komentar
Indonesia. Pembulatan uang/rate = **half-to-even** (banker's). Overflow int64 pada operasi
`Money` menaikkan `MoneyOverflowError`; bagi nol menaikkan `ValueError`.
