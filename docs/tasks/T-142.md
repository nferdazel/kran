# T-142 — Migrasi layar ke komponen bersama (DESIGN v2 fase 4)

Status: **DONE — 13/13 layar (31 Okt 2026)**. Layar kas selesai di T-147. Verifikasi hasil cetak
(T-144) bukan migrasi; layar cetak tidak menulis CSS sendiri.

Rujukan: `DESIGN.md` §11–§12, `docs/DECISIONS.md` D-160, `docs/OPEN_ITEMS.md` O-117.

## Lingkup

Menghapus penulisan ulang aturan visual global di tiap halaman (`apps/web/src/routes/**`) dan
memakai lapisan bersama `packages/ui`: komponen (`Alert`, `Button`, `StatusBadge`, `EmptyState`,
`DataTable`) + kelas tata letak (`.kran-page-header`, `.kran-section`, `.kran-stack`, `.kran-actions`,
`.kran-list-plain`, `.kran-stat`, `.kran-facts`, `.kran-dialog`, `.kran-list-scroll`).

Aturan: perilaku, kontrak data, izin, urutan fokus, heading, label, `aria-*`, dan seluruh teks i18n
tidak berubah. Blok `<style>` hanya boleh berisi tata letak khas layar yang tidak bisa dinyatakan
kelas bersama; menambah aturan global baru di `packages/ui` hanya bila dipakai lebih dari satu
layar.

  bersama diperbaiki.

  bersama saat layar kas pindah (dipakai juga oleh ledger).

  atributnya — ditambahkan di lapisan bersama saat migrasi layar kas.

- CSS mati v1 dihapus dari lapisan bersama (`.kran-card`, `.kran-metric-*`, `.kran-balance-bar*`,

  `ariaLabel` terpisah dari `caption`.
