# T-108 — Panel sesi kas di UI teller

Status: IN_PROGRESS — UI selesai, e2e menunggu fixture dev (T-109).
Prasyarat: T-093 (endpoint sesi), T-088d (layar teller), izin `teller.session.{open,close,read}`

## 1. Masalah

T-093 memberlakukan gerbang: transaksi tunai ditolak `no_open_session` bila tidak ada sesi kas
`OPEN` untuk teller di cabang rekening pada tanggal bisnis berjalan. UI `/app/teller` belum punya
buka/tutup/current, jadi setelah kedua perubahan mendarat layar itu **tidak bisa** menyelesaikan
setoran/penarikan, dan pesan "buka sesi kas dulu" tidak ada tempatnya di aplikasi.

## 2. Lingkup (kecil, satu panel)

Panel "Sesi kas" di atas form transaksi pada `/app/teller`:

- Saat muat halaman: `GET /teller/sessions/current?branchId=<cabang aktif>`.
  - 200 → tampilkan sesi OPEN: `businessDate`, `openingFloat`, `note`, tombol "Tutup sesi".
  - 404 `session_not_open` → tampilkan tombol "Buka sesi".
  - 409/403 lain → pesan galat, form transaksi dinonaktifkan (fail-closed).
- Buka: input float awal (`parseMoneyInput`) + catatan opsional + `Idempotency-Key`.
- Tutup: input kas fisik hasil hitung + catatan opsional + `Idempotency-Key`; setelah 200 tampilkan
  `expectedCash`, `countedCash`, `variance` (tanda + nominal) dan status CLOSED.
- `businessDate` sesi ditampilkan; bila sesi OPEN bertanggal lain, tampilkan peringatan eksplisit
  ("tutup sesi lama dulu") dan nonaktifkan form transaksi sampai ditutup.
- Cabang: pakai cabang aktif yang sama dengan form transaksi (jangan menebak; bila belum ada
  pemilih cabang, gunakan cabang user dari `/auth/me` atau sumber yang sudah dipakai layar lain).
