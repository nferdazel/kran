# T-026 — Kontrak CLI multi-role + jalur skrip ops (O-013)

Status: DONE (bukti di bawah)

## Kenapa
Skrip `ops/` (T-013) mengandalkan `--role=migrate|ctl`, tetapi peran itu belum ada di kode; semuanya
belum pernah dijalankan. Untuk fondasi deploy, kontraknya harus ada **di repo** dan bisa diuji tanpa
menyentuh server produksi.

## Rencana
Berkas: `apps/api/src/main.nim` (parsing peran + perilaku tiap peran), `docs/runbooks/`, uji di
`apps/api/tests/`. Peran minimal: `api` (sekarang), `migrate` (jalankan migrasi lalu keluar dengan
kode status benar), `ctl` (perintah operasional yang aman: mis. `verify-audit`, `param-drift`).
Tidak ada akses server/VPS; hanya berkas repo + eksekusi lokal terhadap DB dev.

## Kriteria selesai
- [ ] `--role=migrate` idempoten dan keluar dengan kode status yang benar (diuji).
- [ ] `--role=ctl <perintah>` punya daftar perintah tertulis + bantuan, minimal satu perintah nyata
      (mis. verifikasi rantai audit) yang diuji.
- [ ] Runbook ops diperbarui agar cocok dengan kontrak yang benar-benar ada; `./task ci` hijau.

## Hasil

- `apps/api/src/main.nim`: peran `migrate` (`--up` default idempoten, `--check` read-only dengan kode
  1 saat ada migrasi tertunda/drift), peran `ctl` (`verify-audit`, `outbox-status`, `daycloser-status`
  → kode 3 "belum ada", `help`), `--root=<dir>`, dan `when isMainModule` supaya perannya bisa diuji
  langsung. `worker` tetap gagal cepat (kode 3) dengan pesan yang menyebut peran yang ada.
- `apps/api/tests/itapi_roles.nim` (baru, 7 test): bantuan/kode keluar, kontrak `verify-audit`
  (utuh 0 / tidak utuh 1, plus konsistensi dengan `verifyChain` pada DB nyata), `outbox-status`,
  `migrate` idempoten (dua kali jalan → 0, tidak ada yang diterapkan), `migrate --check` → 0.
- `docs/runbooks/ops-cli.md` (baru): tabel kontrak peran + arti kode keluar + apa yang dipakai skrip.
- `ops/scripts/migrate.sh`: header diperbarui; `--contract`/`--down` ditolak skrip (kode 3) karena
  biner belum mendukung — bukan diam-diam jadi `--up` (**O-048**).
- O-013 diperbarui: peran `migrate`/`ctl` ada; sisa yang belum: `worker`, freeze gate daycloser.
