# T-155 — Penutupan otomatis rekening dormant bersaldo nol

Status: **DONE (31 Okt 2026)**. Rujukan: O-114, D-174.

## Masalah

Task dormant hanya menandai `DORMANT` dan mereaktivasi; tidak ada jalur penutupan otomatis, sehingga
rekening terbengkalai menumpuk dan tetap tampil sebagai rekening hidup.

## Keputusan (D-174)

- Task baru `deposit.dormant_close` (EOD, non-kritis, `dependsOn` task dormant).
- Menutup hanya rekening yang **masih `DORMANT`**, **saldo nol**, dan aktivitas terakhir lebih lama
  dari `deposit.dormant_close.after_months` (default 24, parameter institusi,
  `NEEDS-COMPLIANCE-REVIEW`). Saldo bukan nol tidak pernah ditutup otomatis.
- Aktivitas terakhir memakai ekspresi subledger yang sama dengan penandaan (D-170).
- Paginasi = `DORMANT` + `CLOSED` supaya status yang berpindah tidak menggeser offset.
- Satu audit `deposit.dormant_close.chunk` per chunk berisi daftar rekening tertutup, ditulis di
  transaksi yang sama; run tanpa perubahan tidak menulis audit.
