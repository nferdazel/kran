# T-170 — UI operator pinjaman (daftar + detail)

**Status**: DONE (2 Nov 2026) · **Deps**: T-169

## Lingkup yang dipilih, dan yang sengaja tidak

UI ini **membaca**: daftar pinjaman dan detail akad (status, saldo, golongan, jadwal aktif, riwayat
versi jadwal). Ini menutup jalur yang benar-benar hilang: tanpa layar ini operator tidak bisa melihat
pinjaman sama sekali tanpa membuka DB.

Aksi tulis (**pencairan, pembayaran, restrukturisasi, hapus buku**) **belum** masuk UI, dan bukan
karena lupa:

- pencairan butuh pemilih rekening anggota (dan uang bergerak begitu tombol ditekan);
- pembayaran butuh rekening sumber + nominal + pratinjau alokasi (pokok/bunga/denda) sebelum commit;
- hapus buku destruktif dan butuh alasan yang diketik.

Masing-masing punya keputusan UX sendiri (konfirmasi, pratinjau, izin yang berbeda per peran). Task
turunan **T-173** mencatatnya; mengerjakannya setengah di sini akan menghasilkan tombol yang
memindahkan uang tanpa pratinjau.

## Scope

1. **`/app/loans`** — daftar pinjaman dengan pencarian `partyId`, filter status, dan batas baris.
   Menampilkan nomor akad, anggota, pokok, status, sisa pokok, dan tanggal cair (kosong = belum cair).
   Baris yang tidak boleh dibaca tidak muncul (scoping cabang dari API).
2. **`/app/loans/[loanId]`** — detail: status, pokok, tanggal cair/jatuh tempo, golongan
   kolektibilitas, saldo (`principalOutstanding`/`interestOverdue`/`penaltyOutstanding`), tabel
   **jadwal aktif**, dan daftar versi jadwal (riwayat restrukturisasi).
3. **Navigasi**: entri `loans` di `nav.ts` untuk peran yang memegang `lending.loan.read`.
4. **i18n** `id` + `en` lengkap; tidak ada string hardcode di komponen.
5. **a11y**: axe `moderate` ke atas × 2 tema × 2 locale, alur kunci (buka daftar → buka detail →
   kembali) tanpa tetikus; empty state dan galat terbaca pembaca layar.

## Invarian yang diuji

- Daftar menampilkan hanya pinjaman yang dikembalikan API; filter status mengubah isi tabel.
- Detail menampilkan **jadwal aktif** dan jumlah versi (setelah restrukturisasi: versi 2).
- `principalOutstanding` `null` (belum cair) ditampilkan sebagai "—", bukan `0,00`.
- Tidak ada string hardcode (spec i18n check + test e2e yang sudah ada).
- Axe lolos di empat kombinasi; navigasi keyboard mencapai tabel jadwal.

## Non-goals

- Aksi tulis (T-173).
- Laporan/agregasi (T-171).
- Cetak akad/slip (sudah ada kerangka `print.ts`; menambah template baru = task sendiri).
