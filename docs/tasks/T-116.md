# T-116 — UI administrasi buku besar (periode, COA, pembalik jurnal)

Status: **DONE** (24 Okt 2026) — layar `/app/ledger/admin`, PR #7.

## Scope

Satu pintu UI untuk pekerjaan admin buku besar yang sebelumnya hanya lewat API/CLI (O-103):

- **Periode**: daftar periode (`startsOn`, `endsOn`, `status`, `closedAt`), buka periode baru,
  tutup periode OPEN dengan alasan wajib. Pra-cek tumpang tindih di klien; server tetap otoritas
  (`period_no_overlap`).
- **COA**: daftar akun dan buat akun baru dengan validasi klien; 400/409 dipetakan ke pesan.
- **Pembalik jurnal**: pilih/tempel `journalId` + alasan wajib; `Idempotency-Key` dipertahankan
  antar-retry. Tidak ada edit/hapus — buku besar immutable.

Tidak masuk: mengubah handler/handler kontrak; tidak ada migrasi.

## Gate izin

- Nav `/app/ledger/admin` butuh `ledger.period.manage` (pengguna baca-saja tidak melihat entri).
- Seksi dalam layar disaring sendiri: `ledger.period.manage`, `ledger.coa.manage`,
  `ledger.journal.reverse` (daftar jurnal tambahan butuh `ledger.journal.read`).
