## Scope

Panel aksi di detail pinjaman untuk status `WRITTEN_OFF`, izin `lending.loan.recovery`:

- rekening sumber (dipilih dari rekening anggota di cabang akad; server tetap penjaga akhir),
- tiga komponen nominal: pokok, bunga, denda (kosong = `0.00`),
- alasan (1–500 karakter),
- pratinjau: setiap komponen + **total** yang dijumlahkan dengan `addMoney` (string + BigInt),
- dialog native dengan focus trap, Esc, pemulihan fokus; `role="alert"` untuk galat total.
