# T-154 — Peristiwa `param.changed` disaring per cabang pelanggan

Status: **DONE (31 Okt 2026)**. Rujukan: O-070, D-173.

## Masalah

`topicsAllowedFor` memakai izin tingkat institusi, jadi pengguna yang izinnya khusus cabang tidak
menerima peristiwa parameter sama sekali. Membuka topiknya tanpa penyaringan akan mengirim peristiwa
**semua** cabang ke semua pelanggan.

## Keputusan (D-173)

1. Gerbang topik memakai `authorizedAnyBranch`; penyaringan peristiwa yang menentukan isi.
2. `EventScope` (`institutionWide`, `branchIds`) dihitung dari grant + pasangan SoD yang sama dengan
   otorisasi HTTP, sekali per pesan `subscribe`.
3. `scopeAllows` menyaring `param.changed` ber-`scope_type = BRANCH`; peristiwa `GLOBAL`/lainnya
   tidak spesifik cabang. Cakupan kosong = tidak ada cabang (gagal-tertutup).
4. Replay `resumeFrom` memakai saringan yang sama.
5. `TopicPolicy.eventScope` wajib, pola `sessionValid` (O-036).
