# T-145 — Baseline akrual per siklus ARO + tenor dari atribut produk (O-109)

Status: **DONE (31 Okt 2026)**. Rujukan: `docs/DECISIONS.md` D-165, `docs/OPEN_ITEMS.md` O-109.

## Masalah

`deposit.interest_accrual.cumulative` dihitung dari `opened_on` dan tidak pernah di-reset. Task
jatuh tempo membayar seluruh `cumulative` pada setiap siklus, sehingga siklus kedua membayar ulang
bunga siklus pertama. Tenor perpanjangan dihitung `maturity_date − opened_on`, yang setelah satu
perpanjangan menjadi dua kali tenor semula.
