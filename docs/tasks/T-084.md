# T-084 — O-072a: tabel & helper idempotency

## Lingkup

Fondasi idempotency untuk endpoint pembuat objek (D-098), tanpa mengubah perilaku endpoint mana
pun: tabel klaim, domain kunci/sidik jari, repo, helper composition root, dan parameter TTL.
Kewajiban header di endpoint menyusul di T-085.

## Bagian spec / keputusan

- D-098: PK `(principal_id, key)`, operasi + hash + respons + expiry, baris ditulis dalam
  transaksi bisnis, replay hanya 2xx, TTL parameter.
- D-094/D-095: nilai TTL adalah parameter teknis, bukan angka di kode.

## Temuan reviewer r1 & perbaikannya

- MAJOR expiry: baris kedaluwarsa dulu dihapus di dalam transaksi klaim, jadi kunci lama tidak
  direplay selamanya meski daycloser belum ada. Test: baris selesai/in-flight kedaluwarsa → klaim baru.
- MAJOR replay status: helper kini mengembalikan **200** untuk replay (D-098), status asli tetap
  disimpan di baris untuk audit.
- MAJOR sidik jari: hash mencakup method, path, query terurut, dan body — dua resource berbeda
  dengan body sama tidak saling mereplay.
- MAJOR test transaksi: ditambah test rollback (body melempar → klaim hilang, retry boleh),
  body non-2xx tidak menyimpan klaim, dan `Retry-After` dari `expires_at`.
- MAJOR header kosong (r2): helper kini memakai `Option[string]`; header tidak ada = `none`
  (operasi biasa), header ada tetapi kosong = `some("")` dan **ditolak** validator. Ada test yang
  membuktikan operasi tidak berjalan untuk header kosong.
- MAJOR sidik jari tak teruji (r2): `canonicalOf` diekstrak dan diuji langsung — method/path/query/
  body membedakan, urutan query tidak mengubah, dan nilai berisi pemisah tidak bertabrakan
  (komponen diberi awalan panjang).
- MINOR jam DB: `completed_at` kini dikirim pemanggil, sama dengan jam klaim.
- MINOR tipe error (r2): salah konfigurasi TTL → `IdempotencyConfigError`, klaim hilang/body non-2xx
  → `IdempotencyStateError`; handler memetakan keduanya ke 500, bukan 400.
- MINOR `Retry-After` (r2): dibatasi 60 detik (konstanta protokol, bukan kebijakan bisnis); klaim
  yang barisnya hilang memakai 1 detik, bukan satu TTL penuh.
- MINOR test saling bergantung (r2): tiap test memakai kunci sendiri dan memeriksa barisnya
  langsung, bukan mengandalkan urutan test.
- MINOR duplikasi validator kunci (platform vs ledger): **utang teknis** — dua modul punya aturan
  sendiri; disatukan ke kernel saat endpoint jurnal ikut memakai helper (T-085).
- MINOR PII `response_body`: dicatat sebagai **O-093**; perlu keputusan masking/retensi sebelum
  T-085 memasang helper di endpoint ber-PII.
- MODULE.md platform diperbarui (repo, migrasi `0001..0021`, tabel baru).

## Catatan

- Helper menerima `Request` pada pintu handler, tetapi intinya (`withIdempotencyKey`) menerima kunci
  mentah supaya bisa diuji tanpa server HTTP.
- Pembersihan baris kedaluwarsa belum dijadwalkan; D-098 menaruhnya di daycloser (belum ada task
  daycloser di Fase 2). Indeks `expires_at` sudah disiapkan.
