# T-084 — O-072a: tabel & helper idempotency

## Lingkup

Fondasi idempotency untuk endpoint pembuat objek (D-098), tanpa mengubah perilaku endpoint mana
pun: tabel klaim, domain kunci/sidik jari, repo, helper composition root, dan parameter TTL.
Kewajiban header di endpoint menyusul di T-085.

## Bagian spec / keputusan

- D-098: PK `(principal_id, key)`, operasi + hash + respons + expiry, baris ditulis dalam
  transaksi bisnis, replay hanya 2xx, TTL parameter.
- D-094/D-095: nilai TTL adalah parameter teknis, bukan angka di kode.

- `modules/platform/migrations/0021_platform_idempotency.sql`

- `apps/api/src/idempotency.nim` (helper `withIdempotencyKey`/`withIdempotency`, TTL dari parameter)

- Test: `modules/platform/tests/tidempotency.nim`, `modules/platform/tests/itidempotency.nim`,
  `apps/api/tests/itapi_idempotency.nim`

## Catatan

- Helper menerima `Request` pada pintu handler, tetapi intinya (`withIdempotencyKey`) menerima kunci
  mentah supaya bisa diuji tanpa server HTTP.
- Pembersihan baris kedaluwarsa belum dijadwalkan; D-098 menaruhnya di daycloser (belum ada task
  daycloser di Fase 2). Indeks `expires_at` sudah disiapkan.
