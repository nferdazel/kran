# T-063 — run e2e macet harus menjadi *gagal terbaca*, bukan menggantung

Status: **DONE** (19 Okt 2026). Sumber: `docs/tasks/T-044.md` H2/H3 + usulan perbaikan #3.

## Masalah

Tidak ada batas waktu tingkat-run. Kalau runner/worker macet (H3: worker tidak keluar; H2: mesin
suspend di tengah run), proses Playwright bisa menunggu 9–12 menit **tanpa** pesan galat yang
menerangkan sebabnya. Gate CI tidak menjalankan e2e penuh (job Web 71 s, tanpa DB), jadi yang
terdampak adalah run lokal/gate pemilik.

## Perubahan

`apps/web/playwright.config.ts`: `globalTimeout: 8 * 60_000` — di atas durasi run penuh normal
(±30 s Playwright di mesin ini) tetapi jauh di bawah 9–12 menit. Saat batas tercapai Playwright
berhenti dengan pesan global timeout, bukan menunggu tanpa akhir.

## Eksperimen (dicatat juga di `docs/tasks/T-044.md`)

| Eksperimen | Perintah | Hasil |
|---|---|---|
| H2 | `caffeinate -i ./task e2e` | 24 passed, Playwright 25,0 s, total 33 s; tidak ada `Entering Sleep` |
| H3 | `PWTEST_CHILD_PROCESS_TIMEOUT=20000 ./task e2e` | 24 passed, 26,2 s; nol "did not exit within" |

Keduanya **tidak** memisahkan H2/H3 karena tidak ada run yang macet — dicatat sebagai hasil nol,
bukan bukti. Nilai yang didapat: kegagalan akibat macet sekarang terbaca (batas 8 menit).
