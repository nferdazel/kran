# T-004 — Skeleton `platform`: pg pool, migration runner, outbox/inbox, audit hash-chain

Status: DONE · Fase 0 · Spec §9, §12.4, §18.2 · Deps: T-002, T-003

## Scope

1. `shared/platform-lib`:
   - `db/config.nim` — bootstrap config dari env (`CBS_DATABASE_URL` dll). Tanpa nilai bisnis.
   - `db/pool.nim` — pool koneksi (`db_connector`) + `withConn`/`withTx`, batas pool & timeout.
   - `log.nim` — log JSON satu baris, tanpa PII (kunci sensitif otomatis di-mask).
2. `tools/dbtools/` — runner migrasi: penemuan, urutan global, checksum anti-drift, idempotent,
   penjaga **expand-only**, `validate|migrate|status|--dry-run`.
3. `modules/platform/` — modul lintas-modul: migrasi `0001..0003` (schema, `audit_log`,
   `outbox`+`inbox`), domain (`audit.nim`, `event.nim`), infrastruktur (3 repo), `MODULE.md`.

## Keputusan desain

- **Hash rantai dihitung di DB** (trigger + `pgcrypto`), bukan di Nim: tidak ada jalur tulis
  yang bisa melewatkannya. Payload kanonik memakai UTC eksplisit + tanggal ISO supaya hasil
  verifikasi tidak bergantung `TimeZone`/`DateStyle` sesi.
- **Immutability lewat trigger** (UPDATE/DELETE/TRUNCATE ditolak). Pemisahan privilege role
  produksi = open item (butuh role non-owner, di luar scope Fase 0).
- **`--check`-style anti-drift**: checksum SHA-256 dihitung `pgcrypto` (bukan implementasi
  sendiri), migrasi yang sudah jalan tidak boleh berubah → `MigrateError`.
- **Definisi parameter dipisah dari nilai pack** (T-003) — tidak berubah di sini.
- **Expand-only dijaga secara struktural**: DDL merusak hanya lolos dengan header
  `-- dbtools:destructive <alasan>`; pemindaian di-anchor pada awal kalimat (identifier seperti
  `audit_log_no_purge_trg` tidak salah tertangkap).
- **Pool menunggu dengan polling `sleep(2 ms)`** di bawah lock, bukan `Cond`, karena
  `std/locks.wait` tidak punya timeout. Batas tunggu tetap ada (`acquireTimeoutMs`).
- **`db_postgres.exec` hanya menerima satu pernyataan** (`PQexecParams`) → skrip multi-pernyataan
  (termasuk badan fungsi PL/pgSQL) dijalankan lewat `PQexec` di `dbtools.execScript`.

## Batas / sisa yang jujur

- **Peminjaman koneksi paralel antar-thread belum diuji** di CI (test pool berjalan
  single-thread: batas tunggu diuji dengan poolSize=1, bukan dengan dua thread). Stress test
  menyusul bersama beban nyata.
- **Anchor harian rantai hash belum ada** (spec §18.2) → penyerang dengan hak tulis penuh bisa
  menulis ulang seluruh ekor rantai. `docs/OPEN_ITEMS.md`.
- **`CBS_DATABASE_URL` hanya bentuk URL tanpa parameter kueri** (tanpa `sslmode`) karena
  `db_connector` menyambung lewat `PQsetdbLogin`. Kebutuhan TLS/mTLS = ADR tersendiri.
- Migrasi `0004+` untuk parameter/user/role menyusul di T-005/T-006; `platform/api.nim` belum ada
  (belum ada konsumen lintas-modul).
- `itplatform` **menghapus schema `platform`**; itu aman hanya untuk DB dev (`cbs_dev`).
- `DYLD_FALLBACK_LIBRARY_PATH` untuk libpq adalah konfigurasi mesin (`.local/dev.env`), bukan repo.
