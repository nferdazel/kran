# T-111 — Klasifikasi simpanan koperasi (pokok/wajib/sukarela/tabungan)

Status: READY (rencana dari memo SME, 23 Okt 2026)
Sumber: spec §23 Fase 2, SME memo (model simpanan), D-095/D-124, T-104

## 1. Keputusan model (memo SME)

- `product.product.savings_kind` nullable: `POKOK | WAJIB | SUKARELA | TABUNGAN`, hanya boleh
  diisi bila `product_type = 'SAVINGS'`; **immutable** (trigger baru, jangan ubah guard lama).
- `product_type` tetap `SAVINGS`; `deposit.account.account_type` tetap `SAVINGS`. Jenis dibaca
  lewat join produk yang di-pin rekening; **tidak** ada kolom baru di `deposit.account`.
- `NULL` = belum terklasifikasi. Jangan backfill, jangan menebak dari kode/nama produk.
- Domain: default field harus "tidak terklasifikasi" (bukan nilai enum pertama).

## 2. Aturan yang ditegakkan di Fase 2

| Aturan | Perilaku |

T-104 wajib selesai lebih dulu: rule berkondisi tidak akan pernah terpilih selama
`postJournalSync` mengirim payload kosong.
