# T-120 — Master cabang + nomor rekening ber-kode cabang

Status: **DONE** (24 Okt 2026) — keputusan pemilik O-104/O-101, D-130.

## Scope

Pemilik memutuskan: **kode cabang 3 digit digabungkan ke nomor rekening**, dan **cabang wajib punya
kode**. Sebelum ini nomor rekening = 10 digit nomor urut global (D-123) dan cabang hanya UUID tanpa
nama (O-101).

1. **Master cabang** — `platform.branch`: `code` tepat 3 digit (`^[0-9]{3}$`, unik), `name`, `status`.
   Migrasi `platform/0030` mendaftarkan cabang pilot `001` / `Cabang Pilot`.
2. **Nomor rekening** — `kode cabang (3) + nomor urut (7)`. Nomor urut tetap global; prefiks
   membedakan cabang dan mencegah nomor sama di dua cabang.
3. **Penegakan** — `POST /api/v1/deposit/accounts` menolak cabang yang belum terdaftar (409
   `branch_not_registered`). UI memetakan alasan itu ke pesan i18n.
4. **Data lama** — migrasi `deposit/0031` memberi nomor baru (dari `deposit.account_seq`) untuk
   rekening yang prefiksnya bukan kode cabangnya; nomor lama tidak didaur ulang.
5. **Operasional** — `ctl create-branch --branch-code=<3 digit> --branch-name=<nama>`, audit
   `branch.create`, kode keluar 3 untuk kode tidak sah/duplikat.

Tidak masuk: endpoint HTTP/UI master cabang (O-101 tetap terbuka untuk itu) dan check digit (O-104
sisa terbuka bila compliance menuntut).
