# T-157 — `VERSION` sebagai satu sumber versi

**Status**: DONE (1 Nov 2026) · **Keputusan**: D-178 · **Deps**: —

## Kenapa

Produksi menyajikan bundle web dari 25 Okt selama ~6 hari sementara CI hijau dan API ter-deploy.
Salah satu akibatnya: tidak ada cara memetakan laporan bug ke kode yang benar-benar berjalan.
`package.json` `0.0.0`, `kran.nimble` `0.1.0`, dan `version.nim` hanya fallback — tiga angka yang
tidak saling mengikat.

## Scope

- `VERSION` (root, plain `X.Y.Z`) = `0.1.0`.
- `tools/gen-version.sh` menulis `apps/api/src/version_gen.nim` (`AppVersion`, `AppCommit`) dan
  `apps/web/src/lib/version.ts` (`APP_VERSION`, `APP_COMMIT`).
- `apps/api/src/version.nim` membaca konstanta generated; `KRAN_VERSION` tetap menang.
- Footer web menampilkan `v{APP_VERSION}` (`.kran-footer__version` di `packages/ui`).
- `./task version`, `./task version-check`, dan `cmd_build` memanggil generator lebih dulu.
- `version-check` masuk `check` dan `check-fast`.

## Kriteria selesai

- `VERSION` == `kran.nimble` == `package.json` == `version_gen.nim` == `version.ts`; salah satu
  melenceng → `./task check-fast` gagal.
- Berkas generated nimpretty-clean (gate `fmt_check`).

## Bukti

`./task build` ok; `./task check-fast` → `ok: v0.1.0` + nimpretty 270 berkas; `svelte-check` web dan
`packages/ui` 0 error; `./task lint-web` ok.
