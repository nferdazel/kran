# T-126 — Gate web yang jujur: e2e ber-DB, unit test web, `ci` menolak tanpa DB

Status: **selesai** 24 Okt 2026. Sumber: audit 24 Okt 2026 BLK-1, TST-1, TST-2, DOC-1.

## Masalah

1. Job CI `web-e2e` tidak punya Postgres/`KRAN_DATABASE_URL`, sedangkan 9 dari 11 spec e2e memanggil
   `test.skip(!process.env.KRAN_DATABASE_URL, …)` di module level. CI hanya menjalankan
   `a11y.spec.ts` (halaman `/`) + `keyboard.spec.ts`; login/maker-checker, teller, vault, ledger,
   print, dan zoom tidak pernah digerbang.
2. `./task ci` tetap mencetak `== CI green` walau integrasi dan e2e di-skip karena DB kosong.
3. Unit test `apps/web` (10 berkas, 121 test) tidak dijalankan gate mana pun; paketnya bahkan tidak
   punya dependensi/script vitest.
4. `docs/ci-jobs.md` menulis `itplatform` hanya menghapus schema `platform` (sudah tidak benar).

## Yang diubah

- `apps/web`: `vitest` 5.0.4 (pin, sama dengan `packages/ui`) + `vitest.config.ts` + script `test`.
- `./task e2e`: menjalankan `vitest run` web sebelum Playwright; log Playwright disimpan dan jumlah
  `… passed` dibandingkan dengan ambang `KRAN_E2E_MIN_TESTS` (default 40) bila DB ada. Ambang ini
  yang mengubah "hijau karena semua di-skip" menjadi gagal.
- `./task ci`: menolak jalan tanpa `KRAN_DATABASE_URL` (opt-out eksplisit `KRAN_ALLOW_NO_DB=1`).
- `apps/web/tests/e2e/db.ts`: `requireDatabase()`; di CI tanpa DB ia **melempar**, bukan skip.
  Sembilan spec memakainya.
- `.github/workflows/ci.yml` job `web-e2e`: `services: postgres:18` + `KRAN_DATABASE_URL`, setup Nim
  + cache nimble + `libpcre3` (karena `./task e2e` membangun binary dan memigrasi DB sendiri).

## Bukti

- `pnpm --filter @kran/web test` → 10 berkas, **121 test lulus**.
- `CI=1 KRAN_DATABASE_URL= playwright test --list` → `requireDatabase` melempar (0 test terkumpul);
  dengan ambang 40, run seperti itu gagal.
- `./task e2e` → **46 passed**, `ok: e2e green: 46 test` (ambang terpenuhi).
- `./task lint-web` dan `./task check` hijau.

## Catatan

- Ambang 40 dipilih di bawah jumlah test yang benar-benar berjalan (46) tetapi cukup tinggi untuk
  menangkap satu berkas spec yang hilang/di-skip. Naikkan bila suite bertambah.
- Job `nim-check` tetap tanpa Node; gate eslint/unit/e2e berada di job `web-e2e` (D-139).
