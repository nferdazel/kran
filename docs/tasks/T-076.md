# T-076 — `product` factory parametrik & effective-dated

Status: **IN REVIEW** (20 Okt 2026). Spec §8, §9.1(5), §10.5, §23. Keputusan: D-076.

## Scope

1. Modul `product`: `product`/`product_version`/`product_param_binding` (migrasi `0001` schema,
   `0002` katalog) dengan EXCLUDE anti-tumpang-tindih, versi immutable, binding wajib minimal satu
   (deferred), binding immutable.
2. Domain `product.nim`: kode/nama/tipe, jendela versi inklusif, binding (namespace `product.`,
   unik, non-null).
3. Repo `product_repo.nim`: produk, versi, binding, versi berlaku, tutup versi sekali.
4. API `handlers_products.nim`: daftar (asOf), detail, buat produk + versi 1, versi baru
   (menutup versi sebelumnya); dua gerbang institusi; izin `product.catalog.read|manage`
   (platform `0017` + grant `0018`).
5. Validasi binding terhadap definisi parameter (terdaftar, tidak deprecated, tipe/enum/batas),
   tanpa float.
6. Event `ProductPublished` + audit `product.publish` dalam transaksi yang sama.
7. Test: `tproduct` (unit), `itproduct` (DB: deferred binding, overlap, immutability, versi
   berlaku), `itapi_product` (HTTP: 401/403/400/404/409/201/200, audit+event, grant bercabang).
8. Dokumentasi: `MODULE.md`, kontrak OpenAPI + klien TS, katalog parameter pilot.

## Asumsi

- Kolom diturunkan dari spec (tidak ada DDL resmi) — dicatat D-076.
