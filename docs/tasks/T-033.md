# T-033 — Pool DB: bukti aman paralel + rapikan klaim (O-011)

Status: READY
Prioritas: P2 (batch "Fase 0 tahan banting")

## Kenapa
Asumsi "pool aman dipakai dari worker thread" belum pernah diuji; komentar pool juga menulis `sleep(2)` "di bawah lock", padahal kodenya di luar lock.

## Rencana
- Harness stress: N thread × M permintaan serentak pada pool kecil → tidak ada kebocoran koneksi, tidak ada deadlock, `statsOf` konsisten.
- Perbaiki komentar yang tidak sinkron; catat batas yang terukur (kapan antrean bertimeout perlu menggantikan polling).
- Jalankan di CI (waktu terbatas, deterministik).

## Catatan
Kalau menemukan masalah nyata, tulis temuan + perbaikan, jangan turunkan ambang tes.
