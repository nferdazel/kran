## 2. Endpoint

- `GET /api/v1/teller/cash-transactions/{transactionId}`
  - field `CashTransaction` + `accountNo` + `narration`; izin `deposit.account.read` + gerbang
    cabang rekening; 404 bila tidak ada.
  - alasan: cetak ulang setelah printer macet, tanpa mengulang transaksi.
- `GET /api/v1/deposit/accounts/{accountId}/statement?from=YYYY-MM-DD&to=YYYY-MM-DD`
  - header rekening (`accountNo`, status, `branchId`) + baris gabungan transaksi tunai dan PB
    (masuk/keluar) dengan `transactionId`/`transferId`, `journalId`, `businessDate`, arah, nominal,
    narasi.
  - subledger, **bukan** rekonsiliasi GL; **tanpa** saldo berjalan per baris.
  - batas rentang/jumlah baris = batas teknis (bukan nilai bisnis); validasi `from <= to`.
  - izin `deposit.account.read` + gerbang cabang.

## 3. UI

- Rute di bawah `/app` agar ikut guard sesi, tetap menampilkan dokumen di layar + toolbar Cetak
  yang hilang saat print.
- CSS: `@page { size: A4; margin: 12mm }`, `thead` berulang, `break-inside: avoid` untuk total,
  `tabular-nums`, token print sudah memaksa tema terang.
- i18n id+en prefix `slip_`/`statement_`/`print_`; tanpa string hardcode.
- Format: `formatMoney(..., { decimals: 2 })`, `formatDate`, cetak `businessDate` (tanpa jam
  browser sebagai "dicetak pada").
- PII minimal: nomor rekening, nominal, narasi; tanpa nama/NIK/alamat.
