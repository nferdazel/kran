## O-107 — pemindaian axe `/app/ledger` pernah kehabisan 30 detik

Penyebabnya beban CPU pemindaian atas tabel saldo, bukan interaksi yang salah. Test pemindaian itu
kini memakai `test.setTimeout(60_000)`; test alur tetap 30 detik, jadi batas longgar tidak menutupi
kelambatan interaksi.

## O-088 — reset schema lokal tidak melepas ekstensi

`resetTestSchemas` menjatuhkan schema per modul, sedangkan `btree_gist`/`pgcrypto` hidup di `public`.
Akibatnya `CREATE EXTENSION IF NOT EXISTS` selalu no-op lokal, sehingga jalur migrasi DB kosong hanya
teruji di CI. Reset kini juga `DROP EXTENSION IF EXISTS btree_gist, pgcrypto CASCADE`; daftarnya
mengikuti `CREATE EXTENSION` di migrasi dan harus ikut diperbarui bila ada ekstensi baru.
