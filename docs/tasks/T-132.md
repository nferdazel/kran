# T-132 — UX operator: PB terkunci, error jaringan, logout di shell, axe 4 layar, 401 terpusat, tanggal UTC, reduced motion

Status: **selesai** 24 Okt 2026. Sumber: audit 24 Okt 2026 UI-1…UI-6, UI-11.

## Masalah

1. **UI-1.** `fieldset disabled={postingBlocked}` membungkus pemilih mode di layar teller. Fieldset
   yang `disabled` mengeluarkan **seluruh** isinya dari urutan fokus, jadi tanpa sesi kas teller
   tidak bisa memilih PB (*pemindahbukuan* = mode `TRANSFER`) lewat pointer maupun keyboard —
   padahal PB justru satu-satunya mode yang tetap boleh.
2. **UI-2.** Login dan ganti kata sandi memanggil `api.POST` tanpa `try/catch/finally`: kegagalan
   jaringan meninggalkan `submitting = true`, tombol mati permanen, tanpa pesan.
3. **UI-3.** Logout hanya ada di `/app` dan `/app/password`. Teller di terminal bersama tidak bisa
   mengakhiri sesi dari layar kerjanya (`/app/teller`, `/app/ledger`, …).
4. **UI-4.** `/app/users`, `/app/products`, `/app/ledger/admin`, `/app/accounts/open` tidak punya
   spec Playwright/axe sama sekali — empat layar paling padat (tabel, panel inline, form bertingkat)
   tidak pernah digerbang aksesibilitas dan tidak pernah dibuktikan bisa dipakai keyboard.
5. **UI-5.** Tidak ada penanganan 401 terpusat: sesi kedaluwarsa meninggalkan UI interaktif yang
   setiap kirimannya gagal.
6. **UI-6.** `formatDate` membangun tengah malam **UTC** lalu memformatnya di zona peramban, sehingga
   di zona negatif tanggal bisnis tampil mundur sehari (slip dan laporan).
7. **UI-11.** `prefers-reduced-motion` hanya menjaga dua aturan; transisi nav, segmented, tabel,
   filter, palette, dan bilah saldo tetap berjalan.

## Yang diubah

- **UI-1** — `disabled` dipindah dari `fieldset.teller-gate` ke kontrol yang memang harus ditahan:
  tujuan PB, nominal, narasi, dan tombol "Tinjau". Pemilih mode tetap aktif sehingga PB bisa dipilih.
- **UI-2** — `try/catch/finally` di `login/+page.svelte` dan `app/password/+page.svelte`; kegagalan
  jaringan → `error_generic`, dan `finally` selalu mengembalikan `submitting`.
- **UI-3** — shell `/app` (`routes/+layout.svelte`) memuat identitas (`app_signed_in_as`), tautan
  ubah sandi, dan tombol keluar; salinan di `/app` dan `/app/password` dihapus (satu aksi = satu
  tombol, supaya tidak ada dua tombol "Keluar" di satu layar). Gaya `.kran-nav__session` di
  `packages/ui/src/components.css`.
- **UI-4** — `apps/web/tests/e2e/screens.spec.ts`: axe × 2 tema × 2 locale untuk empat layar, plus
  satu alur keyboard per layar (panel role buka/tutup, persetujuan draf produk, form bagan akun,
  pemilihan party). Data disiapkan lewat API (draf produk oleh `dev.maker`, party e2e) dan akun
  `dev.console` baru (`platform_admin`, `packs/base/seed/0005_dev_console.sql`) — akun dev yang ada
  tidak memegang `ledger.period.manage`/`platform.user.manage`.
- **UI-5** — middleware `api.use` di `lib/app/api.ts`: respons 401 di luar `/login` →
  `window.location.assign("/login")` (muat ulang penuh: state izin/langganan realtime sudah tidak
  sah). Keputusan diuji sebagai fungsi murni `shouldRedirectToLogin`.
- **UI-6** — `formatDate` memakai `timeZone: "UTC"`; catatan eksplisit bahwa zona per cabang
  (spec §16.2) nanti harus dibangun sebagai tengah malam di zona cabang, bukan memformat instan UTC
  dengan zona lain.
- **UI-11** — satu aturan `@media (prefers-reduced-motion: reduce)` menyeluruh (durasi 1 ms, bukan 0,
  supaya `transitionend` tetap terkirim), menggantikan pendekatan mengejar tiap deklarasi.
- **Pendukung** — pembatas login (T-128) kini membaca `KRAN_LOGIN_MAX_CONCURRENCY` dan
  `KRAN_LOGIN_ATTEMPTS_PER_MINUTE` (default tetap konstanta). Tanpa itu seluruh suite e2e login
  puluhan kali per menit dari 127.0.0.1 dan dijawab 429; `playwright.config.ts` menaikkan batas
  percobaan untuk proses API e2e, sementara pembatasnya sendiri tetap diuji dengan nilai default
  (`tlogin_guard`, `itapi_users`). Dicatat sebagai D-144.

  dengan nilai default).

## Catatan / sisa

- Gate layar administrasi memakai akun `dev.console` (`platform_admin`). Itu akun dev, bukan
  produksi; ia ada di seed dev-only dan tidak ikut `seedBaseFiles` produksi.
- UI-7 (tanggal "hari ini" di `/app/ledger`), UI-8 (`{#key locale}` me-remount), UI-9 (tabel
  `/app`/`ledger/admin` tanpa region), UI-10 (debounce tanpa `AbortController`), UI-12 (`Number()`
  tanpa cek finite), dan UI-13 (tautan "Lanjut" yang bisa 403) tetap terbuka di **T-133**.
- Suite e2e menaikkan batas percobaan login lewat lingkungan. Yang diuji suite itu adalah perilaku
  layar, bukan pembatas; kalau kelak e2e ingin menguji pembatas juga, perlu skenario khusus dengan
  IP/kunci berbeda.
