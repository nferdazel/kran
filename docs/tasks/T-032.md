# T-032 — Drain permintaan berjalan saat SIGTERM (O-047)

Status: READY
Prioritas: P2 (batch "Fase 0 tahan banting")

## Kenapa
`watchStop` langsung `quit(0)` setelah pump berhenti; permintaan HTTP yang sedang jalan dipotong di tengah.

## Rencana
- Tunggu permintaan berjalan selesai dengan batas waktu (dari konstanta teknis, bukan angka bisnis), lalu keluar.
- Test e2e/integrasi: permintaan lambat tetap mendapat respons utuh saat SIGTERM dikirim.
- Perbarui `docs/spikes/O-025-shutdown.md` bila temuan probe berubah.

## Catatan
Batas waktu harus terukur; jangan menahan proses tanpa batas.
