# T-050 — gate CI yang benar-benar menegakkan sesuatu (O-027 sebagian, O-014, O-023)

Status: **DONE** (17 Okt 2026) untuk (a)+(b). **(c) ESLint dikeluarkan → T-057 (BLOCKED)**.
Prioritas: P1 (gate yang hijau tanpa menegakkan apa pun = hijau palsu).
Keputusan terkait: D-051.

## Kenapa

Tiga item terbuka bertemu di satu titik: gate yang terlihat ada tetapi tidak menegakkan apa pun.
Test integrasi tidak pernah berjalan di CI (melewati dirinya sendiri tanpa `KRAN_DATABASE_URL`),
dan gate shellcheck hanya memblokir pada level `error` sementara temuan `warning` sekadar
dilaporkan — dengan alasan jujur bahwa toolnya tidak ada di mesin pengembang.

## Rencana dan hasil

- **(a) Job `db-tests`** (`O-027`, sebagian) — `services: postgres:18`, `KRAN_DATABASE_URL` ke
  `kran_test`, langkah `dbtools migrate` → `dbtools seed --dev` → `./task test`. **Selesai.**
- **(b) `shellcheck -S warning` jadi gate** (`O-014`) — dinaikkan dari `error` ke `warning`,
  fail-closed tanpa tool (pelepasan sadar `KRAN_SKIP_SHELLCHECK=1`), CI memasang shellcheck
  eksplisit. **Selesai.**
- **(c) ESLint** (`O-023`) — **dikeluarkan** → `T-057`. Menambah `eslint`/`eslint-plugin-svelte`
  adalah dependensi baru (AGENTS §1.6 butuh ADR) dan `packages/config/eslint.js` belum ada.

## Bukti

- `./task check` **exit=0**; baris `ok: 7 skrip lolos bash -n + shellcheck (level warning)`.
- `shellcheck -S warning ops/scripts/*.sh` → exit 0, 0 baris temuan (ketujuh skrip ops).
- Harness `cmd_shlint` (fungsi diekstrak apa adanya dari `./task`): tanpa shellcheck → DIE;
  `KRAN_SKIP_SHELLCHECK=1` → lolos dengan pesan; skrip pemicu `SC2034` → DIE (dulu hanya
  dilaporkan — inilah perubahan perilakunya); skrip ops asli → OK.
- `ci.yml` divalidasi (ruby): empat job terbaca; `db-tests` memakai `postgres:18` dan
  `KRAN_DATABASE_URL` ke `kran_test`.

## Sisa jujur

- Job `db-tests` **sudah terbukti**: run CI `39004290391` (commit `9b35fe5`) sukses keempat job,
  termasuk `DB (integrasi, Postgres 18)` — test integrasi kini benar-benar berjalan di CI.
- `O-027` sisa: job `traceability` belum ada. `O-023` tetap terbuka lewat `T-057`.
