## Scope

Give every timestamp property in the contract a real type: `format: date-time` for ISO-8601
instants, `format: date` for date-only values, and keep nullable properties nullable
(`type: ["string", "null"]` plus the format, not a bare `type: string`). Write the list of touched
properties into this file as the work is done, so the count is checkable: 35 unformatted today, 0
expected after.

`openapi-typescript` is expected to keep emitting `string` for both formats, so the regenerated
`schema.d.ts` should be byte-identical. That is the check, not an assumption: if the diff is not
empty, the task stops and reports what changed before committing.

Out of scope: changing response payloads, renaming fields, adding formats to values that are not
timestamps (money strings, ids), and adding new spectral rules beyond what this change needs.

## Acceptance

1. `rg -n 'At:$' -A2 packages/contracts/openapi/kran-api.yaml` shows every timestamp property with
   a `format` line; the report lists them and the count.

3. `./task openapi-gen` then `./task openapi` green, and `git diff
   packages/api-client/src/generated/schema.d.ts` empty.
4. `./task test itapi_auth` green: responses still parse the same.
5. `./task check-fast` stays 8/8.
