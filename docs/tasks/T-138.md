## 4. Kriteria selesai per potongan

- **a**: rumus `bunga = saldo × rate × hari / basis` dengan `Money` (tanpa float), pembulatan
  `HALF_EVEN` skala 2, property test (0 hari = 0, monoton terhadap saldo/rate/hari, basis benar),
  golden test untuk ACT/365, ACT/360, 30/360 termasuk tahun kabisat dan bulan 31 hari.
- **b**: migrasi + kontrak API/COA/rule; tidak ada nilai bisnis di kode; akun `204` masuk COA dasar
  (`NEEDS-COMPLIANCE-REVIEW` untuk kode akunnya). `0064` (deposit) bersifat **contract** karena
  melonggarkan CHECK `account_type` (DROP CONSTRAINT = DDL destruktif) dan terdaftar di
  `ops/migrations/contract-auto.txt`.
- **c**: akrual menulis jurnal harian lewat outbox/`postRuleJournalSync` (idempoten per
  rekening+tanggal), checkpoint tidak pernah mundur, catch-up 3 hari menghasilkan total yang sama
  dengan 3 run harian, run ulang hari yang sama tidak menggandakan jurnal.
- **d**: jatuh tempo memakai `maturity_date`, ARO membuat rekening baru/memperpanjang sesuai
  instruksi, tanpa duplikasi saat run ulang.
- **e**: `last_activity` diperbarui oleh transaksi yang ada, dormant hanya menandai status, dan
  rekening yang bertransaksi kembali keluar dari DORMANT (aturan reaktivasi dicatat).

### Keputusan yang masih dibutuhkan sebelum task jatuh tempo/ARO

1. **Kapan** deposito dianggap jatuh tempo: pada EOD tanggal `maturity_date` (uang sudah tidak
   berbunga hari itu) atau sehari setelahnya?
2. **Ke mana bunga pergi** untuk tiap `aro_instruction`:
   - `NONE`: pokok + bunga ke rekening simpanan anggota (`201`) — D `202`/K `201` dan D `204`/K `201`.
   - `PRINCIPAL`: pokok diperpanjang, bunga ke `201`.
   - `PRINCIPAL_AND_INTEREST`: keduanya diperpanjang — perlu rule baru D `204` / K `202` (bunga
     menjadi pokok) **atau** bunga dibiarkan di `204` dan pokoknya saja yang naik (tidak konsisten
     dengan saldo rekening).
3. **Perpanjangan** memakai tenor semula (`maturity - opened_on`) atau produk/instruksi lain?
4. **Akrual setelah jatuh tempo**: rekening yang menunggu ARO (mis. instruksi `NONE` tetapi anggota
   belum mencairkan) — tetap berbunga?
