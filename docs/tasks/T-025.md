# T-025 — Invarian kursor outbox + test balapan dua koneksi (O-037, O-040)

Status: DONE (bukti di bawah)

## Kenapa
(a) Kursor `seq` outbox hanya aman karena `appendAudit` selalu ditulis lebih dulu; invarian itu tidak
tertulis dan tidak diuji, sehingga penulis event baru bisa membuat peristiwa committed terlewat oleh
pump. (b) Harness test mengompilasi tanpa `--threads:on`, jadi penjaga `activatePending` tidak punya
test balapan dua koneksi yang sesungguhnya.

## Rencana
- Tulis invarian + alasannya di MODULE.md modul platform (dan/atau komentar `outbox_repo`), lalu uji
  urutan itu lewat test yang gagal bila urutan dibalik.
- Aktifkan `--threads:on` pada kompilasi test (perubahan kecil di `task`, hanya untuk daftar test),
  lalu tambah test: dua thread meng-approve nilai yang sama dengan koneksi terpisah + barrier →
  tepat satu berhasil, dan audit/event hanya satu.

## Kriteria selesai
- [ ] Invarian tertulis + diuji (test gagal bila urutan audit/event dibalik).
- [ ] Test balapan dua koneksi ada dan deterministik (tepat satu pemenang), tanpa flaky.
- [ ] `./task ci` hijau; O-037/O-040 ditutup atau sisa keterbatasannya dicatat ulang.

## Hasil

- `task`: `TESTFLAGS = --threads:on` dipakai untuk kompilasi *dan* `nim check` berkas test (sama
  seperti biner API).
- `modules/platform/MODULE.md`: bagian "Invarian: urutan commit == urutan `seq` outbox" + aturan
  penulis.
- `modules/platform/tests/itoutboxcursor.nim` (baru): invarian antar dua koneksi (penulis kedua
  menunggu commit penulis pertama; `seq` meningkat) + karakterisasi bahaya (event tanpa audit lebih
  dulu → kursor melewatkannya).
- `modules/platform/tests/itparam.nim`: test balapan dua koneksi (dua thread, gate bersama) → tepat
  satu pemenang + satu audit approve + satu event outbox.
- Keputusan: **D-032**. O-037 dan O-040 ditandai selesai di `docs/OPEN_ITEMS.md` (sisa yang jujur
  untuk O-037: penegakan lewat disiplin penulis + test, bukan constraint DB).
- Mutasi: lock audit dilepas sementara → test invarian GAGAL; `AND status = 'PENDING'` dilepas
  sementara → test balapan GAGAL. Keduanya hijau setelah dikembalikan.
