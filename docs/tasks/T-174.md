## Scope

Add `apps/api/src` (excluding `/generated/`) to `isScanned`, and give the tool a baseline with the
same semantics as `tools/archcheck/baseline.txt`: a listed finding is accepted, an unlisted one
fails the gate, and a listed finding that no longer occurs also fails ("baseline stale, shrink it").

The rule shape for handlers must be decided explicitly and written into this file before the
baseline is captured, because a handler legitimately holds numbers that are not business values:
HTTP status codes, body-size caps, header lengths, retry-after seconds. Two things are not allowed
as a shortcut:

1. Adding `nomagic:ok` in bulk to make the gate green. `apps/api/src` already has 27 of them in 14
   files, all with a written reason (`# nomagic:ok batas teknis ...`). This task adds none; the
   diff must show zero new escape hatches, and any new one needs a reason in the diff review.
2. Widening `allowedInts` with whatever the run happens to flag. Any addition to the technical
   allowlist is named in the report with the constant it covers.

Out of scope: fixing the findings the baseline will capture. That is the shrink work P0a hands to
later phases, and `docs/BACKLOG.md` T-179 reads the count.

## Acceptance

1. Seed one business value in a handler (for example `const minAge = 17` in
   `apps/api/src/handlers_party.nim`) → `./task nomagic` exit 1, names file, line and value. On the
   parent commit the same seed passes, which is the bug.
2. Seed one technical constant that must stay allowed (for example `const statusOk = 200`) → exit 0,
   and the allowlist entry that makes it pass is named in the report.
3. Remove one line from `baseline.txt` while its finding still exists → exit 1, "new finding".
4. Fix one real baselined finding without editing the baseline → exit 1, "baseline stale"; removing
   that line then makes it green. This is the shrink-only proof.
5. `./task nomagic` on the clean tree exits 0 and prints the baseline count; `./task check-fast`
   stays 8/8.
6. `tools/lint-nomagic/tests/tnomagic.nim` covers the new category and all three baseline outcomes;
   `./task test tnomagic` green.
