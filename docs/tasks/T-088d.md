Menambah tautan "Teller" di `apps/web/src/routes/+layout.svelte` mengubah urutan Tab yang dikunci
`apps/web/tests/e2e/keyboard.spec.ts` (3 tautan jadi 4). Test itu diperbarui bersama perubahan nav

### 2.4 Kriteria lulus (bisa diuji e2e, tanpa mouse)

1. Deep link `?accountId=<uuid>`: Tab mencapai `Nominal` dengan urutan sama seperti tabel 2.1.
2. Ketik nominal, Enter: tinjauan tampil, `document.activeElement` = heading tinjauan.
3. Esc di tinjauan: form kembali, fokus = `Nominal`, nilai nominal masih ada.
4. Enter di tinjauan: tepat satu `POST`, hasil tampil, fokus = heading hasil, live region
   mengumumkan "Transaksi tersimpan. Saldo setelah 250.000,00."
5. Dua Enter cepat tidak mengirim dua `POST` (tombol `disabled` + guard), hasil satu `transactionId`.
6. Gagal 409: fokus = ringkasan galat (`role="alert"`), isian tidak hilang.
7. Tidak ada `tabindex > 0` di halaman, tidak ada klik di berkas test.

## 3. Wireframe teks per layar

### 3.1 Keadaan kosong (belum ada rekening)

```
h1 Teller
Rekening
  Belum ada rekening dipilih.
  Buka halaman ini dari tautan rekening.
```

Tidak ada form transaksi sebelum rekening termuat. Empty state jujur, tanpa data dummy (DESIGN §9).

### 3.2 Rekening termuat, form transaksi (1366x768, zoom 100-125%)

```
+-------------------------------+------------------------------+
| Rekening                      | Transaksi                    |
| 0000000012           [Aktif]  | Jenis                        |
| Saldo saat dimuat             | ( ) Setor (masuk)            |
| (IDR)            250.000,00   | (o) Tarik (keluar)           |
| dimuat 10:42                  | Nominal (IDR)                |
|                               | [300000                    ] |
|                               | 300.000,00                   |
|                               | Keterangan (opsional)        |
|                               | [                          ] |
|                               | [Tinjau]  44 px, primer      |
+-------------------------------+------------------------------+
```

- Kiri `minmax(0,1fr)`, kanan `22rem`; di bawah 1100 px panel kanan turun ke bawah, bukan modal
  (DESIGN §4).
- Nomor rekening: string apa adanya, mono, `tabular-nums`, tanpa pemotongan, tanpa pengelompokan,
  tanpa `maxlength` (D-123: 10 digit provisoris, bentuk final bisa berubah).
- Simbol mata uang di label/judul kolom, bukan di sel (DESIGN §6). Nominal tunai 2 desimal (D-097).
- Baris tabel 34 px, kontrol 32 px, aksi primer 44 px atau 2.75rem (`--control-height-primary`).
- Angka bisa diseleksi dan disalin (tanpa `user-select:none`).

### 3.3 Tinjauan, konfirmasi sebelum transaksi finansial

```
Periksa sebelum disimpan            (heading, fokus masuk ke sini)
Tarik (keluar)            300.000,00
Rekening 0000000012, saldo saat dimuat 10:42: 250.000,00
Keterangan: -
[Simpan transaksi]   [Ubah]          Esc = Ubah
```

Satu lapisan saja (DESIGN §7). Tidak ada modal berlapis dengan isi sama (SME-NOTES §1). Arah ditulis
kata + tanda + posisi, bukan warna saja (spec §15.4).

### 3.4 Hasil sukses

```
h2 Transaksi tersimpan
Tarik (keluar)            -300.000,00
Saldo setelah (IDR)        250.000,00
Nomor transaksi            <uuid>   [Salin]
Jurnal                     <uuid>   [Salin]
Tanggal buku               2026-10-23
[Transaksi berikutnya]  (fokus ke sini setelah Enter)
```

- `balanceAfter` **dari respons** `CashTransaction.balanceAfter`, bukan hitungan lokal.
- "Saldo sebelum" hanya dari `GET` terakhir, berlabel waktu ("saldo saat dimuat 10:42"). UI tidak
  menjanjikan angka itu masih berlaku.
- Tanggal buku dari respons (`businessDate`), tidak dihitung dari jam browser.
- Live region `polite` hanya setelah sukses; `assertive` hanya untuk kegagalan transaksi (DESIGN §8).

### 3.5 Gagal, ditolak, tidak pasti

| Keadaan | Tampilan | Fokus |
|---|---|---|
| 403 tanpa `reason` | "Akun ini tidak punya izin mencatat transaksi tunai." | alert |
| 403 `branch_not_allowed` | "Rekening ini di luar cabang wewenang Anda. Transaksi tidak disimpan." | alert |
| 404 | "Rekening tidak ditemukan. Periksa nomor rekening." | alert |
| 409 `insufficient_funds` | "Saldo tidak cukup untuk penarikan ini. Transaksi tidak disimpan. Periksa saldo, lalu ubah nominal." | alert |
| 409 `period_closed` | "Periode akuntansi sudah ditutup. Transaksi tidak disimpan. Hubungi admin untuk periode berjalan." | alert |
| 409 `account_not_active` | "Rekening tidak aktif. Transaksi tidak disimpan." | alert |
| 400 | `error_bad_request` + rujukan `traceId` | field pertama |
| jaringan / timeout | "Status transaksi belum pasti..." + referensi klien + "Coba lagi" dengan `Idempotency-Key` sama | alert, assertive |
| memuat rekening | `role="status"` "Memuat rekening..." | - |

- Galat tidak auto-hilang (DESIGN §8); rujukan `traceId` ditampilkan dan bisa disalin.
- 409 tidak membawa saldo, jadi copy tidak menyebut angka saldo (jangan mengarang).
- Gagal separuh (DESIGN §7): "Coba lagi" memakai kunci idempotensi yang sama, sehingga retry
  menghasilkan replay 200, bukan transaksi kedua (D-098/D-117).

- Tidak ada pencarian berbasis pola nomor sebelum Q1 diputuskan.
