# T-176 — Pemulihan pasca hapus buku (O-122)

Status: **IN PROGRESS** (2 Nov 2026)
Asal: O-122 (`docs/OPEN_ITEMS.md`) — "putuskan apakah pemulihan dicatat sebagai pendapatan
lain-lain dengan jurnal sendiri, lalu tambahkan alur `POST .../recovery`".

## Keputusan yang dipakai (D-191, perlu persetujuan manusia)

Pemulihan = **pendapatan**, bukan pengurangan piutang, karena `110` sudah ditutup saat hapus buku.
Per komponen: pokok → `409` (pendapatan lain-lain), bunga → `401`, denda → `403`.
**NEEDS-COMPLIANCE-REVIEW**: kode/nama `409` adalah usulan struktur pilot (REG-011 `V!`).
**HUMAN-REVIEW-REQUIRED** (AGENTS §8): jalur ini mengubah laporan laba rugi.

## Scope

- Migrasi: `ledger/0097` (akun `409` + 3 posting rule), `lending/0098` (tabel `lending.recovery`),
  `platform/0099` (izin `lending.loan.recovery`), `deposit/0100` (contract: `tx_type LOAN_RECOVERY`).
- Domain `lending/domain/recovery.nim` — batas kumulatif per komponen, murni + unit test.
- Repo `lending/infrastructure/recovery_repo.nim` — nilai hapus buku, total sudah dipulihkan, insert.
- Handler `POST /api/v1/lending/loans/{loanId}/recovery` — izin, cabang, status `WRITTEN_OFF`,
  rekening sumber (milik anggota, cabang sama, aktif), saldo cukup, jurnal per komponen, subledger
  `LOAN_RECOVERY`, audit + outbox `LoanRecovered`, `Idempotency-Key` wajib.
- OpenAPI + TS client, `ops/migrations/contract-auto.txt` (contract `deposit/0100`).

Di luar scope (task turunan): **T-177** — aksi pemulihan di UI (panel, pratinjau, axe 2 tema × 2 locale).
