## Scope

1. Migrasi `0004_ledger_posting_rule.sql` (`posting_rule` + `posting_rule_line`, kondisi JSONB,
   prioritas, status/effective) dan `0005_ledger_posting_rule_base.sql` (rule contoh idempoten,
   `NEEDS-COMPLIANCE-REVIEW`).
2. Domain `posting.nim`: containment kondisi, pemilihan rule (spesifisitas → priority → ambigu =
   gagal), validasi template (1 debit + 1 kredit), pembentukan baris.

4. Konsumen `apps/api/src/posting.nim`: event akuntansi (`headers.accounting == true`) → inbox →

6. Test: `tposting` (unit), `itposting` (integrasi konsumen), `./task ci` hijau.
