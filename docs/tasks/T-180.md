# T-180 — Gate traceability requirement ↔ kontrol ↔ test (O-027)

Status: **DONE** (2 Nov 2026)
Asal: spec §4.4 & §21.3, O-027, D-199.

## Scope

Job CI `traceability` — satu-satunya job §21.3 yang belum ada — beserta sumber datanya yang bisa
di-review di diff.

Bukan scope: tabel `compliance.regulation/requirement/requirement_control` di database (D-199
menjelaskan kenapa berkas dipilih lebih dulu), dan pengisian seluruh baris §4 (register sengaja
dibatasi pada baris yang sudah punya konsumen di kode).

## Berkas yang disentuh

- `docs/compliance/register.yaml` — register yang dibaca mesin: `id`, `title`, `status`
  (`active`/`deferred`), `controls.params`/`controls.modules`, `tests[].file` + `tests[].name`.
- `tools/traceability/{lib,main}.nim` — validasi fail-closed.
- `task` — target `./task traceability`, dipanggil `check` dan `check-fast`.
- `.github/workflows/ci.yml` — job `traceability` (timeout 15, cache nimble) + filter `paths` yang
  tetap memicu CI untuk perubahan register saja.
- `docs/ci-jobs.md`, `docs/OPEN_ITEMS.md`, `docs/DECISIONS.md` (D-199), `docs/BACKLOG.md`.

## Kriteria selesai

- [x] Requirement `active` tanpa kontrol atau tanpa test menggagalkan gate.
- [x] Parameter yang dirujuk harus ada di `modules/*/seeds/params.yaml`.
- [x] Test yang dirujuk harus ada **dan** berkasnya memuat `test "<nama>"` (bukan hanya nama berkas).
- [x] Gate jalan tanpa Postgres dan masuk gerbang harian (`check-fast`).
- [x] Cakupan register dinyatakan eksplisit supaya tidak terlihat seperti seluruh §4 sudah ter-cover.

## Bukti

- `./task traceability` → `5 requirement aktif punya kontrol + test, 9 deferred`.
- Register yang sengaja dirusak (parameter palsu + nama test palsu) → exit 1 dengan dua temuan:
  `parameter tidak ada di seeds/params.yaml` dan `test tidak ditemukan di …`.
- `./task ci-fast` hijau setelah gate ini masuk (lihat `docs/PROGRESS.md`).
