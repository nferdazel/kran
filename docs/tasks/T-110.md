# T-110 — Command palette Ctrl+K

Status: IN_PROGRESS (implementasi selesai, gate e2e/CI dijalankan pemilik)
Sumber: `docs/BACKLOG.md` T-110, spec §14.3 ("Keyboard-first: shortcut teller (F-keys
terkonfigurasi), command palette (Ctrl/⌘+K), fokus otomatis logis"), `DESIGN.md` §5/§8/§10, T-095 §4

## 1. Masalah

Spec §14.3 menuntut command palette, dan T-095 §4 mencatatnya sebagai pekerjaan yang belum dibuat.
Tidak ada jalan masuk keyboard untuk berpindah layar kerja selain Tab melewati menu: di layar teller
yang padat (rekening → sesi kas → transaksi → hasil), operator harus menekan Tab berkali-kali atau
memakai mouse.

## 2. Keputusan

1. **Aksi = navigasi saja.** Daftar aksi bersumber dari nav yang sudah ada, sekarang satu tempat:
   `apps/web/src/lib/app/nav.ts` (Buku besar, Teller, Parameter) yang juga dipakai menu di
   `routes/+layout.svelte`. Palette **tidak** menyalin aturan izin: halaman tujuan tetap yang menolak
   bila pemakainya tidak berhak (spec §13). Tidak ada aksi POST/transaksi. Karena itu "Keluar" tidak
   masuk palette (itu aksi sesi, bukan navigasi) dan halaman Audit/Produk belum ada sebagai rute
   sendiri, jadi tidak dikarang.
2. **`Ctrl+K` / `Cmd+K` global, kecuali saat fokus di field teks.** Di field teks, `Ctrl+K` punya
   arti sendiri (pengeditan ala Emacs di macOS, pencarian peramban); palette tidak merebutnya.
   Pintasan tetap berlaku dari mana saja di `/app/*` setelah keluar dari field.
3. **`<dialog>` native + `showModal()`**, bukan `<div role="dialog">`: peran `dialog`, modalitas
   (`aria-modal`), lapisan teratas, dan `inert` latar datang dari platform (spec §17.1 "elemen
   semantik dulu, ARIA kemudian"). `role="dialog"` **eksplisit ditulis tidak** karena peran itu sudah
   implisit pada `<dialog>` dan menambahkannya hanya menghasilkan warning kompilator a11y
   (`a11y_no_redundant_roles`) pada `svelte-check --fail-on-warnings`.
4. **Focus trap ditulis eksplisit** (Tab membungkus `input` ↔ aksi terakhir, `Shift+Tab` ke arah
   sebaliknya) walaupun peramban juga menahan fokus di dialog modal: perilaku yang diuji harus
   perilaku yang ditulis, bukan versi peramban. Fokus dikembalikan ke elemen pemicu saat ditutup.
5. **Selama modal terbuka, keystroke tidak diteruskan ke halaman** (`stopPropagation` di handler
   dialog): halaman di belakang inert, jadi `Esc`/F-key teller tidak boleh bereaksi terhadap ketikan
   di palette.
6. **Pencarian substring tanpa peduli huruf besar/kecil atas label id + en + href**, sehingga
   "buku besar" dan "ledger" sama-sama menemukan `/app/ledger` tanpa bergantung bahasa UI. Navigasi
   panah (dari field pencarian = aksi pertama/terakhir) + `Enter` pada field = hasil teratas.
7. State kosong jujur: satu kalimat ("Tidak ada perintah yang cocok."), bukan daftar kosong.

Batas (jujur): tidak ada tombol pemicu di toolbar (palette murni keyboard; di perangkat sentuh belum
ada jalan masuk), aksi hanya sepanjang daftar nav yang ada, dan ganti bahasa saat palette terbuka
menutup palette (subtree `/app` dibangun ulang oleh `{#key locale}` di layout akar).
