## Scope

One shell: grouped sidebar (MAIN MENU / FUNCTIONS), 56px topbar with breadcrumb and right slot, page
header, 32px toolbar. `/login`, `/app/print/*` and error pages stay outside it. Below 1024px the
sidebar becomes off-canvas with a focus trap and Escape, and the topbar keeps a menu button.

Deliberately not in scope: per-screen toolbars and content, the drawer (T-290), table changes (T-288).

## Acceptance

Navigating `/app/*` renders the shell once, with `#main` as the skip-link target and `aria-current`
on exactly one nav item. Below 1024px, opening the panel traps Tab inside it, Escape closes it and
returns focus to the menu button. Routes outside the shell render without a sidebar in DOM.

migration is measured against a clean baseline. Until a later GATE-LOG entry is green, none
