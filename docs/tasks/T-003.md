# T-003 — Tooling gate: archcheck, lint-nomagic, paramgen

Status: DONE · Fase 0 · Spec §5.1, §5.2, §10.3, §10.4 · Deps: T-001, T-002

## Scope

Tiga tool penegak aturan + test-nya, semuanya masuk ke `./task check` (menggantikan SKIP):

1. `tools/archcheck` — batas arsitektur (Clean Architecture, spec §5.1/§5.5):
   - `domain` tidak boleh menyentuh `application`/`infrastructure`/`interface`, driver DB,
     atau `std/asyncdispatch`/`std/osproc`.
   - `application` tidak boleh menyentuh `infrastructure`/`interface`/driver DB.
   - Modul hanya bicara lewat `api.nim` modul lain (aturan C) — menembus internal modul lain
     (`deposit/infrastructure/...`) = pelanggaran.
   - `shared/kernel` hanya stdlib + sesama kernel.
   - Escape hatch `# archcheck:ok <alasan>`; tanpa alasan = pelanggaran tersendiri.
2. `tools/lint-nomagic` — tidak ada nilai bisnis di kode (spec §10.4):
   - Pindai hanya `modules/<m>/domain/**` + `modules/<m>/application/**`.
   - Angka di luar allowlist teknis `{0,1,2,12,24,60,100,1000,1024}` = pelanggaran;
     **semua** literal desimal = pelanggaran (rate/fee/ambang).
   - Pola string bernilai bisnis: `Rp…`, numerik murni, numerik berpemisah, berakhiran `%`.
   - Escape hatch `# nomagic:ok <alasan>`.
3. `tools/paramgen` — parameter: kode ⟺ definisi (spec §10.3):
   - Sumber: `modules/<m>/seeds/params.yaml`; validasi key/tipe/scope/schema/regulasi.
   - Output deterministik: `shared/kernel/generated/paramkeys.nim`,
     `packages/contracts/src/generated/params.ts`,
     `packs/base/generated/param_definitions.sql`, `packs/<pack>/generated/param_values.sql`.
   - `--check` (dipakai `./task check`) gagal bila artefak di disk ≠ hasil generate, atau
     ada artefak yatim.

## Keputusan desain

- **Tiga tool berdiri sendiri** (tidak saling import). Klasifikasi lapisan (~12 baris) sengaja
  diduplikasi di archcheck & lint-nomagic supaya satu gate tidak bisa menjatuhkan gate lain.
- **Definisi parameter dipisah dari nilai pack**: `param_definition` (pack-independent, di
  `packs/base`) vs `param_value` (per segment pack). Menghindari FK ke definisi yang belum
  ada dan membuat urutan instalasi pack eksplisit.
- **Nilai seed ≠ fallback kode** (spec §10.3): header SQL dan komentar menyatakan aplikasi
  tetap gagal-cepat (`ParamNotFound`) bila parameter aktif tidak ada.
- **Semua seed ditandai `NEEDS-COMPLIANCE-REVIEW`** (spec §1.8) sampai diverifikasi.
- **Kode hasil generate tidak diformat ulang** oleh nimpretty (`fmt_files()` di `./task`),
  tetapi **tetap** di-`nim check`. Tanpa ini, `./task fmt` akan mengubah byte artefak dan
  membuat `paramgen --check` mustahil hijau.
- `paramgen` menolak `type: duration` sampai ada tipe `Duration` di kernel (jangan
  menebak semantik satuan).

## Catatan / batas jujur

- Deteksi string lint-nomagic berbasis **pola**, bukan semantik: `"batas harian"` tidak bisa
  dikenali sebagai nilai bisnis oleh tool ini. Bagian itu tetap tugas review.
- `lint-nomagic` saat ini masih 0 temuan karena belum ada `modules/*/domain` di repo.
  Efektivitasnya baru teruji lewat fixture (unit test) dan probe sementara di atas.
- Seed pack `base`/`bpr`/`koperasi` yang nyata baru ada di T-005; `packs/base/generated/`
  sekarang hanya berisi header + "belum ada definisi parameter".
- Artefak generate **di-commit** (kontrak terlihat di PR); `paramgen --check` yang menjaga
  kesesuaiannya.
