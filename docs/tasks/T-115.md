# T-115 — Buka rekening simpanan dari UI (+ pencarian anggota)

Status: **DONE** (24 Okt 2026) — PR #8.

## Scope

Menutup celah O-103 butir 2: `POST /api/v1/deposit/accounts` sudah ada, tetapi tidak ada layar
yang memanggilnya dan tidak ada endpoint pencarian party (hanya `GET /parties/{id}`).

1. **Backend** — `GET /api/v1/parties?query=&branchId=&limit=`
   - Izin `party.party.read`; `branchId` (bila ada) digerbang `authorizedAtBranch`.
   - Tanpa `branchId`, hasil dibatasi cabang yang boleh dibaca pemanggil (`readableScopeFilter`);
     pemanggil tanpa grant berbatas melihat semua cabang.
   - `query` minimal 2 karakter; `limit` bawaan 20, maksimum 50; masukan salah → 400.
   - Cari CIF berawalan **atau** `display_name` ILIKE; penyaringan cabang di SQL agar `LIMIT`
     berlaku setelah penyaringan (pola `listAudit`).
   - Bentuk ringkas: `partyId`, `cif`, `kind`, `displayName`, `status`, `branchId` — tanpa KYC.
2. **Web** — `/app/accounts/open`
   - Pencarian anggota ber-debounce 300 ms (min 2 karakter), cabang ditampilkan baca-saja dari party.
   - Pilih produk SAVINGS yang punya versi aktif; kirim `POST /deposit/accounts` dengan
     `Idempotency-Key` per identitas, tombol nonaktif selama pending.
   - Sukses: nomor rekening, saldo, tautan statement. 409 (`party_not_active`, `branch_mismatch`,
     `product_not_active`) dan 403 dipetakan ke pesan i18n.
   - Nav bergate `deposit.account.manage`.
