## Per ticket

Every ticket inherits: tokens only (no raw hex in components), no page-specific CSS in
`packages/ui`, no new dependency, axe on the migrated screens in both themes at 1440 and 360,
contrast test grows and never shrinks, and the existing i18n keys win over new ones.

### T-286 Input / Select / Checkbox (Field folded in)
- `Field` stops existing as a wrapper: label, hint, error live on the control's props and wire to
  `aria-describedby` (id generated by the control, not by the page).
- Heights: 40 field, 32 only inside Toolbar. Radius and border from tokens, border colour is
  `--color-border` (`#7C848F`, 3.49:1) - never the mockup's `#C8CDD3`, D-202 rejected it.
- States to render, each with a visible difference: default, hover, focus, disabled, invalid,
  readonly, filled. Focus ring is one ring, identical for mouse and keyboard.
- Error text uses the error ink token, not red on red; the control gets `aria-invalid="true"`.
- Select keeps the native element (keyboard and mobile behaviour is the reason). Checkbox keeps
  a real `input`; the hit area may grow to 40 but the box stays 16.

### T-287 Button
- Sizes 32 (toolbar) / 40 (field) / 40 primary. Variants primary, secondary, quiet, destructive.
- Hover: quiet and secondary go to `--surface-2`; primary changes brightness 1.06 only, no colour
  shift, no shadow change. Active is one step darker than hover, not a new colour.
- Loading keeps the label, adds `aria-busy="true"`, blocks the second click. Disabled does not
  swap the cursor to `not-allowed` on primary (it reads as an error), it just stops.
- Icon slot 16, gap 8. Never icon-only without `aria-label`.

### T-288 DataTable
- Row 40 default, 36 compact; header 36; sticky header; totals row bold with a rule above.
- Two-line row slot: primary line 13/600, second line 11 muted. Numeric columns right-aligned and
  `tabular-nums`. Wrapper is `role="region"` + one tab stop + `aria-label` naming the table.
- Selected row: 2px inset accent bar on the left + `--surface-2` fill + `aria-selected`. Hover is
  `--surface-2` only. Selection must survive sort and pagination.
- Sorting: `aria-sort` on the active header only, one direction indicator, 12px.
- At 200% zoom the table scrolls inside its own box; no card conversion.

### T-289 Money inside DataTable (risk `full`)
- Symbol once per column header, never per cell. Right-aligned, `nowrap`, `tabular-nums
  slashed-zero`, negatives with a minus that is not a colour-only signal (parentheses or a minus,
  pick one and use it everywhere).
- Column width must not jump when a value goes from 3 to 7 digits: reserve the max width of the
  column.

### T-290 Drawer 520
- 520 fixed width, full height, `--surface`, `--shadow-2`; scrim `rgb(14 16 19 / .32)` light and
  `.56` dark. Width 100% below 640px.
- Non-negotiable, these came from Sari's negative controls on the mockup (both FAILED there):
  1. Esc closes and focus returns to the row that opened it, not to `body`.
  2. `aria-modal="true"` must be honest: Tab stays inside. If the drawer cannot trap, drop the
     attribute and do not claim modal.
- Heading receives focus on open; heading is the drawer's `aria-labelledby` target.
- States: open, loading, error (with retry), plus the unsaved-change confirm on close.
- Opened from a table row, closing must not scroll the table away from that row.

### T-291 Report / print
- Outside the shell: `/login`, `/app/print/*`, error pages. Slip A5 at 12/11, statement A4, same
  heading block repeated on page 2. Print colours come from tokens with a `print` override; no
  shadows, no scrim, no interactive control visible.
- Numbers keep the table rules above; a report that prints with per-cell currency symbols is a
  defect.

### T-292 State sweep
- Lists: loading, empty, no-match, error(retry), denied. Forms: default, invalid, submitting,
  failure, success. Drawers: open, loading, error.
- Three different empties, never one sentence for all: no data yet (teaches the first action),
  no match for the current filter (offers clearing the filter), denied (names the permission and
  who grants it).
- Error states reserve their height so the table does not jump when they appear.

## Terminology rulings (from Rina's audit, decided here)

- Navigation and copy say **Kas besar** (not "Vault kas"), **Kasir** (not "Teller"), **Tutup kas**
  for close cash. Code identifiers keep `vault` / `teller`. `docs/DOMAIN.md` already says this.
- `ledger_empty` currently describes a journal on a screen that shows balances - rewrite it for
  balances.
- `loans_empty` is a no-match sentence: it becomes `loans_empty` (no data yet) plus
  `loans_empty_no_match`. Same split for `ledger_*` and `vault_empty_no_match` with a `{status}`
  placeholder that receives the translated label, never the enum.
- Nav group labels stay the four domain groups in `apps/web/src/lib/app/nav.ts`. `MAIN MENU` and
  `FUNCTIONS` in SPEC §2 are a structural sketch, not copy.
